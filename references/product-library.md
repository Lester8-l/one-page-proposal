# 產品庫：5 險種賣點框架

> **這裡是框架，不是產品目錄。**具體保額、保費、條款責任一律以你手上的產品資料為準；
> 沒有的數字留 `【待補】`，**不要憑印象填**。下面的「參考量級」是市場慣例，用來判斷客戶開出的數字是否合理。

---

## 1. 醫療險（Medical）

**定位**：用小額保費擋住大額、不確定的醫療開支。回應「驚一場病傾家蕩產」。

| 客戶觸發信號 | 「醫療費好貴」「公立排隊太耐」「唔想動用積蓄睇醫生」 |
|---|---|
| 底層需求 | 大額醫療開支的風險轉移 |
| 對應關注 | 醫療費、動用積蓄、輪候時間 |

**賣點框架**
- 住院及手術開支實報實銷　→　唔使為醫藥費動用你嘅積蓄
- 入住私家醫院　→　唔使等公立輪候
- 保證續保至 XX 歲　→　唔會因為病過而買唔返
- 墊底費 HK$XX，超出部分全賠　→　保費低啲，小病自付大數保險扛

**要填的數字**：年度保障上限、終身上限、墊底費、病房級別、保證續保年齡、等待期。

**合規注意**：不得寫「全賠／包賠」——要寫「超出墊底費部分按保單賠償」。
「實報實銷」要對應保單的合理及慣常費用定義。

---

## 2. 危疾險（Critical Illness）

**定位**：確診指定疾病即一筆過賠償，補住患病期間的收入缺口。**這是香港客戶最常買的險種之一。**

| 客戶觸發信號 | 「唔想病咗冇收入」「康復期唔知幾長」「做手術要停工」 |
|---|---|
| 底層需求 | 患病期間收入中斷（不是醫藥費！醫藥費是醫療險的事） |
| 對應關注 | 收入中斷、康復開支、家庭開銷照要俾 |

**賣點框架**
- 符合保單定義下確診，一筆過賠 HK$XXX 萬　→　補住約 X 年收入缺口，唔使急住復工
- 賠償不限用途　→　供樓、交租、請看護都可以用
- 保障 XX 種疾病，含 X 種早期疾病預支　→　唔使等到最嚴重先有錢
- 多次賠償／癌症持續賠償　→　舊病復發都仲有保障

**要填的數字**：保額、保障疾病數目、早期疾病預支比例、多重賠償次數與間隔、生存期要求、保費與供款年期。

**保額參考量級**：一般取年收入 **2–5 倍**，或「足夠覆蓋 2–3 年家庭總開支」，以較高者為準。
客戶若只開出年收入 1 倍，通常不足以度過康復期，值得在文字稿裡用一句話溫和點出。

**合規注意**：一筆過賠償必須寫成「符合保單定義下」，
不可寫「確診即賠」（會被理解為任何確診都賠）。這是危疾卡最常見的合規地雷。

## 3. 儲蓄險（Savings / Endowment）

**定位**：用時間換取穩定累積，做中長期目標的資金池。回應「啲錢放銀行縮水」。

| 客戶觸發信號 | 「想啲錢有增長」「放銀行冇息」「想留筆錢俾細路」 |
|---|---|
| 底層需求 | 現金購買力被通脹蠶食／中長期目標資金 |
| 對應關注 | 通脹、目標儲備、留給家人 |

**賣點框架**
- 供款 X 年，其後資金持續滾存　→　唔使供一世，時間幫你累積
- 第 10 年預期現金價值約 HK$XX 萬〔非保證〕　→　可作小朋友升學儲備
- 保單可傳承／更改受保人　→　財富可以跨代延續
- 鎖定部分利潤（鎖息）　→　市場波動時保住成果

**要填的數字**：年供款、供款年期、名義金額、預期現金價值（分保證／非保證）、回本期、鎖息機制。
**每一個回報數字都要拆開標示保證與非保證部分。**

**合規注意**：
- **絕對不能**寫「保證回報」「穩賺」「零風險」「像定存」「儲蓄替代品」。
- 預期利益必須標「非保證，須視乎保險公司實際投資表現」。
- 任何回報率／派息率同句標「過往表現不代表將來」。
- 不要用「複息滾存」「利息」形容分紅——用「非保證紅利」等保單用語。

## 4. 人壽險（Life）

**定位**：把「如果你唔在」的經濟缺口，換成一筆確定的錢給家人。回應「我走咗屋企點算」。

| 客戶觸發信號 | 「供緊樓」「兩個細路仲細」「太太冇做嘢」「父母要我養」 |
|---|---|
| 底層需求 | 家庭經濟支柱的身故缺口 |
| 對應關注 | 房貸、子女教育、家人生活費 |

**賣點框架**
- 身故賠償 HK$XXX 萬　→　足夠清還樓按，家人唔使搬走
- 每年保費相對低，槓桿高　→　用細錢撬動大保障
- 可加附加危疾／意外保障　→　唔止走咗有賠，病咗都有
- 保單可指定受益人，直接賠付免遺產程序　→　家人最快攞到錢

**要填的數字**：身故保額、保費、保障年期、是否含現金價值、受益人安排。

**保額參考量級**：房貸餘額 + 子女教育估算 + 3–5 年家庭開支 − 現有資產與既有保額。
這個缺口算是方案卡上最有說服力的一個數字，值得在文字稿裡列出來。

**合規注意**：不得暗示「必定賠償」；自殺條款、等待期等除外責任在正式保單說明，卡上可加註「部分情況除外，詳見保單條款」。

---

## 5. 意外險（Personal Accident）

**定位**：保費最便宜、覆蓋突發傷殘與意外醫療。常作主險的附加保障。

| 客戶觸發信號 | 「做嘢有危險」「成日周圍走」「後生仔唔知會發生咩」 |
|---|---|
| 底層需求 | 突發失能／被動收入中斷 |
| 對應關注 | 收入中斷、意外醫療、家人負擔 |

**賣點框架**
- 意外身故或永久傷殘賠 HK$XXX 萬　→　突發事故都有筆錢頂住
- 意外醫療實報實銷　→　睇急症、跌打都唔肉赤
- 每週／每月傷殘津貼　→　休養期間收入唔會斷晒
- 保費低，可加在主險上　→　用細錢補住一個大缺口

**要填的數字**：意外身故／傷殘保額、意外醫療上限、津貼金額與期數、職業級別、保費。

**合規注意**：「意外」有保單定義（通常需外來、突發、非疾病），不可寫成「任何受傷都賠」。

## 跨險種通用：一張方案卡上要出現哪些數字

無論哪個險種，客戶最終只想知道五件事。方案卡上**至少要答到其中四件**：

| # | 客戶想知 | 卡上放哪 |
|---|---|---|
| 1 | 保幾多（保額） | 數字條大字 或 要點裡的 HK$ 數字 |
| 2 | 保咩（保障範圍） | 方案要點 3 條 |
| 3 | 幾多錢（保費） | 數字條 |
| 4 | 供幾耐（年期） | 數字條 |
| 5 | 幾時有錢收／賠（觸發條件） | 要點的「→」前半句或 footer 註 |

**保額與保費的呈現原則**：保額用大字（客戶在意「有幾多」），保費用小字放數字條
（不要讓保費成為視覺焦點，除非客戶主動問價——那時才把保費往前放）。
